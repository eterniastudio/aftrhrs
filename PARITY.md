## Fixed in the QA pass (fm-qa)

- **Chest Key recipe follows config.yml**: `aftrhrs:chest_key` is no longer a datapack JSON. `LocksModule` builds it
  from `locks.key.recipe`, `locks.key.ingredients`, `locks.key.material` and messages.yml `locks.key.name/lore`, and
  puts it in the server's recipe list through `RecipeInjector.own` (the fm-progression recipe manager mixin, now also
  for module-owned recipes; survives datapack reloads). Rebuilt only when those settings change; removed while
  `modules.locks` is off, as on Paper (`Bukkit.removeRecipe`).
- **Shop keepers take no potion effects** (Paper `Keepers.onPotion`): `FeatherEvents.EFFECT_ADD`.
- **Mob conversions can be cancelled** (Paper `EntityTransformEvent`): new `FeatherEvents.MOB_CONVERT`
  (`MobConvertMixin`, HEAD of `Mob.convertTo`). Keepers never become witches / zombie villagers (before: the conversion
  ran and the witch was discarded afterwards); hologram mob lines never convert.
- **Codex entry panel** (client pet screen): variant swatches and the shiny star wrap inside the panel and the
  description stops above them, so they no longer overlap the text on short windows.
- **Thrown Tidecaller** has a name (`entity.aftrhrs.thrown_relic_trident` in the hand-written `en_us.relics.json`);
  the `aftrhrs:furniture` item tag got its translation (`en_us.tags.json`; Fabric's dev warning about untranslated
  tags is gone).
- `tools/parity.py`: fm-furniture packages evaluated like the rest (no ⏳), fm-cohesion removals (`pet_model*`,
  `items*`, ItemExport keys) marked ⚠️ with the reason, moved classes mapped (`tools/Relics` → `altars/BossRelics`,
  `power/Generators`, `curios/CurioDisplays`), hand-checked furniture verdicts.

## Works differently on purpose (⚠️ highlights)

- Oraxen/ModelEngine/MythicMobs plumbing (items-loaded events, pack bridge, mechanic/condition registration,
  ModelEngine hitbox clicks) has no counterpart: content is native and loads at mod init.
- Storage terminals and connectors are real blocks (hardness 1.5, blast resistance 1200, immovable): the 17 Paper
  listeners that guarded the barrier + display have nothing left to guard. Same for curios, gadgets and power pieces:
  block entities + client renderers replace the base entities and overlay displays.
- Goob Coin crafting/smelting/brewing/anvil guards: the native coin is in no recipe or tag. Custom fish: no vanilla
  cooking recipe matches them, so the no-cook guard and `fishing.no-cook` are unused.
- Trade is a native screen (`TradeMenu`); the chest-GUI pane/lore keys (`trade.gui.*-lore`, `pane-*`, `countdown`,
  `state-line`) are unused.
- Furniture rotation (sneak + empty hand) is the content block's own (90 degree steps, the block's hit sound);
  curios.yml `rotate.*` is unread. Module hooks (hat stand wobble, rope pull) still claim their clicks first.
- Ropes are `minecraft:climbable`: vanilla ladder sliding (0.15 blocks/tick instead of Paper's 0.12, ladder sounds);
  gadgets.yml `slide-speed` / `slide-sound` are unread.
- The pet whistle calls pets directly (no MythicMobs signal): `pet-whistle.signal`, `mob-type-prefix`,
  `message-unavailable` are unread.
- Companion: the Blockbench model streaming (`pet_model*`) and the server item export (`items*`, `aftrhrs:server_*`
  tabs, `companion.creative.*`) were removed by fm-cohesion: menus draw the native GeckoLib creatures, native items have
  real creative tabs.
- Nametags are client-only displays (never block teleports, nothing to detach on death/portal); tab/nametag health
  is polled per tick instead of on damage/heal events.
- `companion.latest-mod` / `companion.outdated*`: dropped, client and server are one jar.
- EssentialsX import (`homes.import-essentials-homes`, spawn.yml), `take-over-commands`: Paper-only, nothing to do.
